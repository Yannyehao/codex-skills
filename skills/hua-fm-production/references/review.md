# 整版审片

制作方在交付前完成整版审片。用户复看用于表达偏好和决定取舍。

## 建立检查清单

- 核对实际送审文件的版本、总时长与帧率。由实际剪辑时间线列出原底片边界、替换段两端、手势落点、口型窗边界、结束语起止和片尾留白。将用户反馈逐条加入，查同源素材的复用处。
- 检测整片相邻帧的变化，分别检查固定背景、眼周与头部位移、嘴部和手纸。按异常峰值安排复查；项目有量测脚本时优先复用。单帧很小的全幅变化也可能遮住局部快回头或嘴形异常，局部单列。
- 对改动点、排列出的峰值和片尾，按原时间码提取前后片段。近景看头转与回正速度、瞳孔方向、眼镜边缘、开口及合口形状、手指和纸边。原速确认动作是否连续，必要时按帧定位失败。

## 复核并交付

- 区分嘴形和声画同步。观察讲话时的嘴角、下颌、开合与音节，尤其是带笑、变表情及口型窗切换的位置。声画对齐分数用于定位偏移，嘴形观感用近景和原速复看判定。
- 比较问题片段、上游底片和修订结果。写时间码、实际现象、处理和结果。对已通过的手势或片尾保留用户认可的节奏，若原画面本身有缺陷，可在保留节奏的前提下修复。
- 最终导出的完整视频从 00:00 按 1× 播放。另复看片头、所有修过的区间和整个片尾。按时间码记录检查内容与结论。播放进度和解码帧数用于证明覆盖，视觉结论来自专项片段与全片复看。用静音后台审画面时，声轨与同步单独验并如实注明。
- 验收记录归档实际文件、检查点、已修问题和未核验范围。有可复现缺陷就先修再检。交付给用户的是完成制作方检查的版本。
